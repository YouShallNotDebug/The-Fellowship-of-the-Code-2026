## AI Assistance

We used AI (ChatGPT) to support us in refining the logic.

We knew what we wanted the code to do and mostly wrote it ourselves and let AI support us with bugs we couldn't solve on our own and give us ideas when we didn't know how to implement a certain feature.

## Lessons Learned

We learned that:

- even small JavaScript changes can strongly affect the user experience
- adding dynamic behavior requires careful connection between logic and interface elements
- debugging helped us better understand how data flows through the application
- understanding existing code was just as important as writing new code
